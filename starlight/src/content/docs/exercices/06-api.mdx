## Niveau 2 : L'API en JSON

<Aside type="syntaxe" title="Sur la persistance">
Ces exercices portent sur les échanges de requêtes et de réponses, pas sur le stockage. La création, la modification et la suppression renverront donc la ressource concernée sans l'enregistrer durablement. La persistance dans une base de données est un sujet ultérieur.
</Aside>

### Exercice 5 &ndash; La liste des salons en JSON

**API**

Créez la page `api/salons.php`. Ce point d'accès retourne la liste des salons en JSON, pour un programme qui souhaite les données sans la présentation. Annoncez le format avec l'en-tête approprié.

<Highlight couleur='ambre'>Attention au chemin : le fichier se trouve dans `api/`, alors que les données sont dans `data/`. Utilisez `__DIR__` pour un chemin fiable.</Highlight>

<Checkpoint question="Indice">
`header('Content-Type: application/json; charset=utf-8')` annonce le format, puis `json_encode` produit le JSON.  
Depuis `api/salons.php`, le fichier de données se trouve à `__DIR__ . '/../data/salons.php'`. L'option `JSON_UNESCAPED_UNICODE` garde les accents lisibles.
</Checkpoint>

{/* <Checkpoint question="Solution">

```php
<?php
// decoupe/api/salons.php
$salons = require __DIR__ . '/../data/salons.php';

header('Content-Type: application/json; charset=utf-8');
echo json_encode($salons, JSON_UNESCAPED_UNICODE);
```

Test avec curl :

```sh
curl http://localhost/decoupe/api/salons.php
```

### Exercice 6  Filtrer avec des paramètres de requête

**API et paramètres**

Enrichissez `api/salons.php` pour qu'il accepte deux filtres dans la chaîne de requête : `?ville=Montréal` ne retourne que les salons de cette ville, et `?promo=1` ne retourne que les salons en promotion. Les deux filtres peuvent se combiner.

<Checkpoint question="Indice">
Lisez les filtres dans `$_GET`. Appliquez `array_filter` sur la liste pour chaque filtre présent. Après un `array_filter`, les clés d'origine sont conservées, ce qui produirait un objet JSON plutôt qu'un tableau : `array_values` réindexe la liste avant l'encodage.
</Checkpoint>

{/* <Checkpoint question="Solution">

```php
<?php
// decoupe/api/salons.php
$salons = require __DIR__ . '/../data/salons.php';

$ville = $_GET['ville'] ?? null;
if (is_string($ville) && $ville !== '') {
    $salons = array_filter($salons, fn($s) => $s['ville'] === $ville);
}

if (($_GET['promo'] ?? '') === '1') {
    $salons = array_filter($salons, fn($s) => $s['promotion'] === true);
}

header('Content-Type: application/json; charset=utf-8');
echo json_encode(array_values($salons), JSON_UNESCAPED_UNICODE);
```

Test avec curl :

```sh
curl "http://localhost/decoupe/api/salons.php?ville=Montréal&promo=1"
```

</Checkpoint> */}

### Exercice 7 &ndash; Enregistrer un salon avec POST

**API et POST**

Ajoutez la prise en charge de la méthode POST à `api/salons.php`. Une requête POST transporte un salon en JSON dans son corps. Lisez ce corps, vérifiez que le nom et la ville sont présents, puis répondez avec le statut `201` et le salon créé. Si les données sont incomplètes, répondez avec le statut `400`. Une requête GET conserve le comportement des exercices précédents.

<Checkpoint question="Indice">
Consultez `$_SERVER['REQUEST_METHOD']` pour aiguiller.  
Un corps JSON se lit avec `file_get_contents('php://input')`, puis `json_decode(..., true)`.  
Vérifiez les champs avec `isset` avant de construire le salon. Attribuez un nouvel identifiant, par exemple `count($salons) + 1`.
</Checkpoint>

{/* <Checkpoint question="Solution">

```php
<?php
// decoupe/api/salons.php
$salons = require __DIR__ . '/../data/salons.php';
header('Content-Type: application/json; charset=utf-8');

$methode = $_SERVER['REQUEST_METHOD'];

if ($methode === 'GET') {
    $ville = $_GET['ville'] ?? null;
    if (is_string($ville) && $ville !== '') {
        $salons = array_filter($salons, fn($s) => $s['ville'] === $ville);
    }
    if (($_GET['promo'] ?? '') === '1') {
        $salons = array_filter($salons, fn($s) => $s['promotion'] === true);
    }
    echo json_encode(array_values($salons), JSON_UNESCAPED_UNICODE);
    exit;
}

if ($methode === 'POST') {
    $donnees = json_decode(file_get_contents('php://input'), true);

    if (!is_array($donnees) || !isset($donnees['nom'], $donnees['ville'])) {
        http_response_code(400);
        echo json_encode(['erreur' => 'Le nom et la ville sont requis.']);
        exit;
    }

    $nouveau = [
        'id'        => count($salons) + 1,
        'nom'       => (string) $donnees['nom'],
        'ville'     => (string) $donnees['ville'],
        'note'      => 0,
        'promotion' => false,
        'horaire'   => '',
        'services'  => [],
    ];

    http_response_code(201);
    echo json_encode($nouveau, JSON_UNESCAPED_UNICODE);
    exit;
}

http_response_code(405);
echo json_encode(['erreur' => "Méthode $methode non prise en charge."]);
```

Test avec curl :

```sh
curl -X POST \
     -H "Content-Type: application/json" \
     -d '{"nom":"Coupe Express","ville":"Laval"}' \
     http://localhost/decoupe/api/salons.php
```

</Checkpoint> */}

### Exercice 8 · Modifier et supprimer un salon

**API, PUT et DELETE**

Complétez `api/salons.php` avec deux méthodes supplémentaires. `PUT` modifie un salon désigné par `?id=...` à partir des champs reçus en JSON, et retourne le salon mis à jour. `DELETE` supprime le salon désigné par `?id=...` et retourne un statut `204` sans corps. Dans les deux cas, un identifiant introuvable donne un statut `404`. Réutilisez la fonction `trouverSalon` de l'exercice 2.

<Checkpoint question="Indice">
Le même aiguillage sur `$_SERVER['REQUEST_METHOD']` sert pour `PUT` et `DELETE`. Ces requêtes ne viennent pas d'un formulaire HTML, mais d'un outil comme Bruno, Postman ou curl. Pour `PUT`, lisez l'identifiant dans `$_GET`, retrouvez le salon, puis remplacez ses champs par ceux du corps JSON. Le statut `204` signifie « pas de contenu » : aucune donnée ne suit.
</Checkpoint>

<Checkpoint question="Solution">

```php
<?php
// À intégrer dans decoupe/api/salons.php, avec la fonction trouverSalon.

function trouverSalon(array $salons, int $id): ?array
{
    foreach ($salons as $salon) {
        if ($salon['id'] === $id) {
            return $salon;
        }
    }
    return null;
}

if ($methode === 'PUT') {
    $id = (int) ($_GET['id'] ?? 0);
    $salon = trouverSalon($salons, $id);

    if ($salon === null) {
        http_response_code(404);
        echo json_encode(['erreur' => 'Salon introuvable.']);
        exit;
    }

    $donnees = json_decode(file_get_contents('php://input'), true) ?? [];
    $salon['nom'] = (string) ($donnees['nom'] ?? $salon['nom']);
    $salon['ville'] = (string) ($donnees['ville'] ?? $salon['ville']);

    echo json_encode($salon, JSON_UNESCAPED_UNICODE);
    exit;
}

if ($methode === 'DELETE') {
    $id = (int) ($_GET['id'] ?? 0);

    if (trouverSalon($salons, $id) === null) {
        http_response_code(404);
        echo json_encode(['erreur' => 'Salon introuvable.']);
        exit;
    }

    // Dans une vraie application, la suppression aurait lieu ici.
    http_response_code(204); // 204 No Content
    exit;
}
```

Test avec curl :

```sh
curl -X PUT \
     -H "Content-Type: application/json" \
     -d '{"ville":"Longueuil"}' \
     "http://localhost/decoupe/api/salons.php?id=2"

curl -X DELETE "http://localhost/decoupe/api/salons.php?id=2"
```

</Checkpoint>
